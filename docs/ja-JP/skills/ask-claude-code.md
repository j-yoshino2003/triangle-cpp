# ask-claude-code

> 正本: `.claude/skills/ask-claude-code/SKILL.md`（英語）。

## このスキルの目的

Claude Code 自体の仕様・設定・拡張方法に関する質問を受け取り、**組み込みの `claude-code-guide` エージェント**（公式ドキュメント参照専用）に調査させて、根拠のある回答を日本語で返します。

対象となる質問の例:

- 機能の有無・使い方（「フックで◯◯はできる?」「サブエージェントの定義方法は?」）
- 設定の意味・書き方（`settings.json` / `settings.local.json` / 権限 / 環境変数）
- スラッシュコマンド・キーボードショートカット
- MCP サーバーの接続・管理
- Claude Agent SDK / Claude API の使い方

## ユーザー入力

質問文を引数として受け取ります。

### 引数チェック

質問が空の場合は、以下を表示して **処理を中断** してください：

```
エラー: Claude Code について調べたい質問を記述してください。

使い方:
  /ask-claude-code <質問>

例:
  /ask-claude-code PreToolUse フックで特定のコマンドだけブロックできる?
  /ask-claude-code settings.local.json と settings.json の優先順位は?
```

## 実行フロー

1. **エージェント起動**: Agent ツールで `subagent_type: "claude-code-guide"` を起動し、ユーザーの質問をそのまま渡す。
   - 質問が日本語の場合もそのまま渡してよい（技術用語・設定キー名は原文を保持する）。
   - このプロジェクト固有の文脈（ハーネス構成・ローカル vendor プラグイン等）が回答に必要な場合は、質問に補足として添える。
2. **回答の整理**: エージェントの回答を日本語で要約・整理してユーザーに提示する。
   - 設定例・コマンド例はコードブロックで示す。
   - エージェントが参照したドキュメントの URL があれば併記する。
3. **不確実性の扱い**: エージェントの回答で確認できなかった点は、`.claude/rules/common/answer-policy.md` に従い断定せず「未確認」と明示する。

## 注意事項

- このスキルは **調査専用**。設定ファイルの変更が必要になった場合は、回答を提示した上でユーザーの指示を待つ（勝手に変更しない）。
- ネットワークが利用できない環境では、エージェントが公式ドキュメントを取得できない場合がある。その際はエージェントの既知知識のみで回答し、その旨を明示する。
